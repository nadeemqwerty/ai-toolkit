# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do NOT** open a public issue
2. Email the maintainer or use GitHub's private vulnerability reporting feature
3. Include steps to reproduce and potential impact

## Scope

This repository contains templates, skills, and scripts. Security concerns may include:
- Shell injection vulnerabilities in scripts
- Credential exposure in templates or examples
- Unsafe subprocess calls in Python tools

## Response

We aim to acknowledge reports within 48 hours and provide a fix within 7 days for confirmed vulnerabilities.
